▚ C64 Coder

Describe a Commodore 64 program and Claude will write it. Try:

🎮 Controller

Bluetooth game controllers work as the C64 joystick: d-pad or left stick to move, A/B/X/Y or shoulder buttons to fire, Start = RETURN, Select = RUN/STOP. Pick port 1 or 2 under Joystick.

Export

Files work on a real Commodore 64 through an SD2IEC, Kung Fu Flash, 1541 Ultimate, Pi1541 or a disk transfer cable, and in emulators such as VICE.

Import

Open a .prg, .d64, .bas, .asm or .txt file.

Create a key at console.anthropic.com. It is stored only on this device and sent only to api.anthropic.com.

Emulator ROMs

The app ships with the free MEGA65 Open ROMs (LGPL-3). Their BASIC is unfinished, so BASIC programs run in the app's built-in BASIC V2 interpreter on top of the emulated machine. For the most faithful results, load your own original C64 ROM files (basic, kernal and chargen, e.g. from a VICE installation or C64 Forever). You can pick all three at once.

Emulation

The C64 itself always runs at real PAL speed (50 frames, 985,248 CPU cycles per second), so programs, music and games keep their correct timing. This setting only changes how often the picture is redrawn.
